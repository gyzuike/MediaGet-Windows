MediaGet Windows 使用说明
适用版本：Windows 10 / 11，64 位

一、第一次使用

1. 双击“MediaGet-Windows-x64.exe”。
2. 首次启动会自动解压运行组件，请稍等片刻。
3. 软件窗口出现后即可使用，无需另外安装 Node.js 等开发工具。
4. 解析和下载需要联网。升级或更换版本前，请先退出正在运行的旧版。

建议第一次使用时，先设置下载目录：
点击顶部菜单“文件 → 设置下载目录…”，选择保存视频或图片的文件夹。设置会自动记住，重启后仍然有效。

二、解析和下载视频

1. 在抖音、小红书等平台复制视频或笔记的分享链接。
   也可以复制包含链接的整段分享文案。
2. 将内容粘贴到软件主界面的输入框，点击“开始解析”。
3. 等待解析结果出现，按需要预览视频、选择清晰度，或选择要下载的图片。
4. 点击结果中的“下载”或“下载视频”。部分平台需要在“下载选项”中选择具体文件。
5. 查看右下角的下载状态：
   · 正在准备下载：已收到下载请求，正在等待服务器响应。
   · 下载中：显示进度条、已下载大小和速度。
   · 下载完成：文件已经保存到电脑。
   · 下载中断或已取消：本次下载未完成，需要时可重新下载。
6. 下载完成后，点击条目右侧的文件夹图标或“打开文件夹”，即可打开文件所在目录，并选中刚下载的文件。

补充说明：
· 服务器没有提供文件总大小时，会显示活动进度条，无法显示准确百分比。
· 文件较大、网络较慢时，请耐心等待，可通过“取消”停止下载。
· 同名文件会自动编号，例如“视频 (1).mp4”，不会覆盖已有文件。
· 面板收起后，点击“文件 → 下载状态”可重新打开。
· 如果下载交给系统浏览器处理，保存位置以该浏览器的设置为准。
· 音乐搜索和解析可切换到主界面的“音乐解析”，按页面提示使用。

三、平台提示需要登录时

不必先登录所有平台。遇到“需要登录”、登录失效或部分内容无法解析时，再登录对应平台即可。

1. 点击顶部“账号”菜单，选择对应平台。
2. 在弹出的官网窗口中完成登录或验证。
3. 如果软件识别到登录状态，会自动保存会话并应用到解析服务。
4. 如果登录后没有自动保存，可点击该窗口顶部的“保存当前会话”。
5. 看到“会话已保存并应用”的提示后，返回主界面，重新点击“开始解析”。

“会话”可以理解为网站用于记住登录状态的信息，软件通过 Cookie 保存它。“保存当前会话”只表示保存了当前网站 Cookie，并不保证网站已确认登录成功。

注意：
· 一次打开一个账号窗口；更换平台前，请先关闭当前账号窗口。
· 微博、汽水音乐和最右使用“保存当前会话”方式，不自动判断登录成功。
· 部分平台没有完整的网页登录入口，或会限制内嵌浏览器登录，例如 Google / YouTube。登录菜单不代表所有平台都能完成网页登录。
· 登录可能过期。过期后可重新打开对应账号窗口登录并保存。
· 账号 Cookie 保存在本机，请勿把自己的配置目录发给其他人。

四、支持的平台

链接解析区包含以下 12 个平台的账号入口和配置项：
抖音、哔哩哔哩、快手、微博、小红书、汽水音乐、西瓜视频、最右、AcFun、X（Twitter）、Instagram、YouTube。

TikTok 始终启用，无需安装或打开开关；TIKTOK_COOKIE 配置项会在启动时自动补齐。
不同平台、不同内容的可用性会受地区、网络、登录状态及平台风控影响。保存登录信息不会解除私密、付费或其他内容权限限制。
小红书登录已实际使用确认；其他平台未逐一用真实账号验证。

五、常用菜单

文件 → 下载状态：重新打开右下角的下载面板。
文件 → 设置下载目录…：更换以后下载文件的保存位置。
文件 → 打开下载目录：打开当前设置的下载文件夹。
文件 → 打开配置文件（Cookie）：手动编辑平台 Cookie。
账号 → 对应平台：打开平台账号窗口。
帮助 → 打开配置与日志目录：查看设置文件及排查问题所需的日志。

更换下载目录只影响之后的下载，不会搬移之前下载的文件，也不会改变已经开始的下载任务。

六、手动配置 Cookie（可选）

通常优先使用“账号”菜单，不需要手动修改配置。

如需手动配置：
1. 点击“文件 → 打开配置文件（Cookie）”。
2. 找到对应平台的配置项，在等号后填写自己账号的完整 Cookie，保持在同一行。
   例如小红书对应 XHS_COOKIE，抖音对应 DOUYIN_COOKIE。
3. 保存文件，退出软件后重新打开，使手动修改生效。

不要把 Cookie 填到其他平台的配置项中。随附的 settings.env.example 只是空白模板，不需要用它覆盖已有配置。软件启动时会自动补齐缺少的平台配置项，并保留已有的值。

七、常见问题

1. 点击下载后暂时没有百分比？
先看右下角是否显示“正在准备下载”。这时请求已开始，服务器尚未返回文件。开始传输后会更新状态；文件总大小未知时不会显示准确百分比。

2. 小红书等平台提示需要登录？
通过“账号”菜单登录对应平台，保存会话后重新解析。仍失败时，可在平台 App 中重新复制分享链接，检查内容是否已删除、私密或需要额外权限。

3. 平台账号窗口打不开？
软件会先尝试系统网络设置，失败后再尝试直接连接。若两种方式均失败，提示中会显示具体错误。请检查网络、系统时间和代理设置；排查时提供平台名称及错误文字即可，不要提供 Cookie。

4. 下载文件保存在哪里？
点击“文件 → 打开下载目录”，或点击已完成条目中的“打开文件夹”。尚未自选目录时，按原有保存方式选择位置。

5. 原下载目录不可用？
可能是文件夹被删除、移动，或移动硬盘已断开。请通过“文件 → 设置下载目录…”重新选择；目录不可用时，软件会提示本次另选保存位置。

6. 下载中断或速度很慢？
检查网络、磁盘空间和下载目录写入权限，然后重新下载。也可能是平台直链已过期，可重新解析后再下载。本版未提供跨重启的断点续传。

7. 点击文件夹图标提示找不到文件？
文件可能已被移动、重命名或删除。该按钮定位的是下载完成时的实际保存路径。

八、配置文件与隐私

配置及日志目录：
%APPDATA%\mediaget-desktop

主要文件：
· settings.env：各平台 Cookie，按原有设计以明文保存，属于敏感登录信息。
· desktop-settings.json：自选下载目录设置。
· server.log、login-network.log：运行及登录窗口联网日志。

运行组件目录：
%LOCALAPPDATA%\MediaGetDesktop\0.1.24-default-tiktok1

可将以上路径粘贴到 Windows 文件资源管理器地址栏打开。日常使用不需要手动操作这些目录。
向他人分发软件时，只分享随附的交付文件，不要附带自己电脑上的配置目录或账号浏览会话。排查日志前也应检查是否包含个人信息。

九、随附文件

MediaGet-Windows-x64.exe：日常运行的软件。
使用说明.txt：本说明。
settings.env.example：空白配置模板。
SHA256-下载文件定位版.txt：EXE 的 SHA-256 校验值，供需要核对文件完整性的人使用。
MediaGet-Windows-下载文件定位版源码.zip：原项目及最终桌面适配源码，普通使用者不需要解压或运行。

YouTube 最高画质与自动合并版

先开启系统 HTTP/HTTPS 代理，再启动软件。解析 YouTube 链接后，默认提供本次可获取的最高画质；也可在下载选项中选择较低清晰度。
点击下载后，软件自动下载视频和音频，并调用内置 FFmpeg 无损封装为一个 MKV 文件，不需要手动合并或额外安装组件。最高画质取决于视频本身、YouTube 返回的可用格式、登录状态和地区限制，不会把低清视频放大成高画质。
右下角分别显示下载视频、下载音频、正在合并和下载完成。视频、音频各有自己的进度，切换阶段后百分比重新计算属于正常情况。合并过程中可能没有准确百分比，请等待“下载完成”再打开文件。也可取消下载/合并。
文件保存在已设置的下载目录；没有设置时会弹出保存窗口。同名文件自动编号，不覆盖已有文件。完成后点击文件夹图标可选中最终文件。
最高画质可能使用 VP9/AV1 等编码，播放时需要支持对应编码及 MKV 的播放器。
下载和合并会临时同时占用分离文件与成品的空间，请预留充足磁盘空间；成功或取消后会清理本次临时目录。
原有平台账号、Cookie、自选目录、下载状态与文件定位功能保留。
组件解压目录：%LOCALAPPDATA%\MediaGetDesktop\0.1.24-default-tiktok1；原账号配置和下载目录继续沿用。
内置 yt-dlp 2026.10.26、FFmpeg 9.0.2。第三方许可证及构建说明位于运行组件 resources/app/tools 中。
验证：软件内自动下载与合并通过，成品同时含视频和音频；4K 公共视频的一秒测试片段合并后保留 3840×2160 视频及 AAC 音轨；取消下载及临时文件清理检查通过。
